# Vorschau, Govindas Higher Taste

Gestaltungsentwurf für die Website von Govindas Higher Taste Catering Services,
Potsdam. Dieses Repository dient ausschließlich dazu, den Entwurf zum Anschauen
im Browser bereitzustellen.

Der Entwurf ist nicht die veröffentlichte Website des Unternehmens. Alle Seiten
tragen ein noindex, sie sollen in Suchmaschinen nicht auftauchen.

Bilder und Logo stammen von Govindas Higher Taste Catering Services und werden
hier nur zur Abstimmung des Entwurfs verwendet.
